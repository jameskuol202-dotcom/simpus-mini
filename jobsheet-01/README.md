# Jobsheet 1 — SIMPUS-Mini

HTML5 page structure for a mini library system. No CSS or JavaScript yet —
this jobsheet focuses on semantic HTML structure (`header`, `nav`, `main`,
`section`, `article`, `footer`), HTML tables, and HTML forms.

Open `index.html` directly in a browser to start. See `documentation/` for
the full jobsheet write-up.
