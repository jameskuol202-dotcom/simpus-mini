# Jobsheet 2 — SIMPUS-Mini

CSS3 styling basics applied on top of the Jobsheet 1 HTML structure.
No HTML structure changes — only one new file (`assets/css/style.css`)
and one `<link rel="stylesheet">` line added to each page's `<head>`.

Covers: CSS reset & `box-sizing: border-box`, Flexbox (header/navbar),
`max-width` + `margin: auto` centring, CSS Grid (statistic cards),
table styling with `:nth-child(even)` zebra stripes, form styling, and
`:hover`/attribute selectors.

Open `index.html` directly in a browser to view.
