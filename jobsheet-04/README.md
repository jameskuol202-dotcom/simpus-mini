# Jobsheet 5 & 6 — SIMPUS-Mini

This project continues the SIMPUS-Mini HTML/CSS project and implements the Week 4 practical requirements:

- JavaScript DOM and events
- JavaScript hamburger navigation
- Delete confirmation
- Live table search
- Client-side form validation
- ISBN validation using digits and hyphens only
- JSON data
- Fetch API with async/await
- try/catch/finally error handling
- Dynamic book and member table rows
- Event delegation for dynamically created Delete buttons
- "Showing X of 10 books" counter

## Run the project

Do not open the HTML files with file:// because Fetch API requests to JSON will be blocked by the browser.

Recommended: VS Code + Live Server.

Open this folder in VS Code, right-click `index.html`, then choose **Open with Live Server**.

You can also use PHP if installed:

```text
php -S localhost:8000
```

Then open the localhost address shown by the server.
